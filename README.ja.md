> **正式リリース — v0.1.1。** 日常的な実使用に向けた版ですが、すべての Windows アプリとの互換性は引き続き確認が必要です。

Pinte は、主にマウスを使う人が Windows 画面の必要な部分を拡大し、独立したレンズウィンドウで正確にクリックまたはドラッグして、キーボードなしで元の画面へ戻れるようにするアプリです。

## できること

1. 元の画面で四角形のソース領域を選択します。
2. その領域を独立したリアルタイム拡大レンズで開きます。
3. レンズ内で普段どおりクリックやドラッグをします。
4. 表示されているレンズの操作で元の画面に戻ります。

ソース枠とレンズは別々に移動・サイズ変更できます。標準/コンパクトレイアウト、上/下ツールバー、ズーム、手のひらツールによるパン、ソース領域の再編集、レイアウトの記憶に対応しています。

## ダウンロードと実行

1. [v0.1.1 リリース](https://github.com/ai-blink/pinte/releases/tag/v0.1.1) から `Pinte-v0.1.1-win-x64.zip` をダウンロードします。
2. ZIP を書き込み可能なフォルダーに展開します。
3. `Magnifier.App.exe` を実行します。
4. **Screen area** を選び、ソース枠を調整してから拡大レンズを開きます。

配布 ZIP は 64 ビット版 Windows 10 または Windows 11 向けの自己完結型パッケージです。別途 .NET ランタイムをインストールする必要はありません。

## 安全性と互換性

- 画面キャプチャ非表示は既定でオフであり、設定から変更できます。有効にすると Pinte の補助ウィンドウを画面キャプチャから除外し、レンズが無限に重なって見えるフィードバックループを防ぎます。
- ソース領域の編集、レンズのサイズ変更、キャプチャ失敗、復帰、終了の前には入力転送を停止します。一時的なキャプチャ失敗は自動で再試行し、新しいフレームを受け取った後にのみ操作を自動再開します。手動で復帰または終了した場合は再開しません。
- セキュアデスクトップ、保護されたコンテンツ、管理者権限で動作するアプリ、リモートセッション、アプリごとの入力ポリシーにより、キャプチャや入力転送が妨げられる場合があります。重要な操作で使う前に対象アプリで確認してください。
- Pinte はローカルのライブ拡大ツールです。画面キャプチャをアップロードまたは保存しません。

## ソースからビルド

必要なもの: Windows と .NET 9 SDK。

```powershell
dotnet build Magnifier.slnx --nologo
dotnet test Magnifier.slnx --nologo
```

マルチモニター、DPI、コンパクトレンズ、キャプチャ復旧、ドラッグの手動確認については、[検証ガイド](doc/manual-validation.md)と[コンパクトレンズのシナリオ](doc/compact-lens-validation.md)を参照してください。

## 現在の状態

`v0.1.1` は設定可能な画面キャプチャ非表示、1 行の設定リスト、移動できる折りたたみレンズ切り替えを追加します。主要なクリック・ドラッグフローには自動回帰テストがありますが、実際の対象アプリでの動作は、利用する Windows 環境で引き続き検証が必要です。再現可能な問題は [GitHub Issues](https://github.com/ai-blink/pinte/issues) で報告してください。
