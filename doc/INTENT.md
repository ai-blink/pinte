# Magnifier 제품 의도

## 사용자 문제

안구마우스로 브라우저 기반 마스크 페인팅, 이미지 편집, 3D 페인팅을 할 때 미세한 포인터 이동과 지속 드래그가 어렵다.

## 제품 목표

- 사용자가 화면의 사각 영역을 선택하면, 이동·크기 조절 가능한 확대창에서 그 **보이는 화면 영역**을 조작한다.
- 확대창의 실시간 Down → Move → Up 조작과 점 지정은 특정 창이 아니라 선택 영역의 물리 화면 좌표에 정확히 대응한다.
- 사용자가 A와 B를 지정하면, 표식과 직선 계획을 먼저 확인하고 카운트다운 뒤 한 번의 직선 획을 실행하며 항상 입력을 해제한다.

## 수락 기준

- A/B 표식의 중심과 사용자가 미리보기 이미지에서 누른 지점이 일치하고, 두 표식 사이의 직선 계획이 즉시 보인다.
- 확대된 미리보기에서 지속 조작한 짧은 드래그가 같은 화면 좌표의 아래 앱으로 실시간 전달된다. A→B 한 획만 되는 상태는 이 기준을 충족하지 않는다.
- A→B 실행 시 확대창이 입력을 가로채지 않으며, 선택한 화면 영역 아래에 보이는 앱으로 한 번의 획이 전달된다.
- 브라우저 마스크 페인팅 화면과 Blender 5.2에서 위 동작을 각각 수동 확인한다. 이는 호환성 검증 대상일 뿐, 런타임의 대상 창 제한이 아니다.
- Esc, 창 닫기, 포인터 capture 손실 뒤 눌린 마우스 입력이 남지 않는다.
- 실제 입력이 불가한 권한·대상 상태는 동작한 것처럼 보이지 않고 원인을 표시한다.

- 대상 앱의 도구·레이어·색상 제어
- 자유 경로 녹화·재생
