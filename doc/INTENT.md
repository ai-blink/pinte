# Magnifier 제품 의도

## 사용자 문제

안구마우스로 브라우저 기반 마스크 페인팅, 이미지 편집, 3D 페인팅을 할 때 미세한 포인터 이동과 지속 드래그가 어렵다.

## 제품 목표

- 사용자가 화면의 사각 영역을 선택하면, 이동·크기 조절 가능한 확대창에서 그 영역을 조작한다.
- 확대창의 Down → Move → Up을 원본 화면 좌표로 정확히 환산해 대상 앱에 전달한다.
- 사용자가 A와 B를 지정하면 카운트다운 뒤 한 번의 직선 획을 실행하고 항상 입력을 해제한다.

## 수락 기준

- 첫 검증 대상인 브라우저 마스크 페인팅 화면에서 영역 지정, 확대창 이동, 짧은 획, A→B 획을 완료한다.
- Esc, 창 닫기, 포인터 capture 손실 뒤 눌린 마우스 입력이 남지 않는다.
- 실제 입력이 불가한 권한·대상 상태는 동작한 것처럼 보이지 않고 원인을 표시한다.

## 비목표

- 안구 추적기 전용 SDK 통합
- 대상 앱의 도구·레이어·색상 제어
- 자유 경로 녹화·재생
