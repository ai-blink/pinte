# 컴팩트 렌즈·원본 표시 정책 수동 검증

이번 기능은 **NEEDS_USER_UI_CHECK**다. 실제 UI·대상 앱 클릭/드래그와 테스트 실행은 사용자가 담당한다. 이전의 “아주 잘됨” 확인과 별개로 기록한다.

원본 작업공간: `C:/ai/projects/magnifier`.
표준 실행본: `src/Magnifier.App/bin/Debug/net9.0-windows/Magnifier.App.exe`.
사용 중인 앱은 사용자가 복귀 후 닫는다. 에이전트는 앱 종료·포커스·입력 조작을 수행하지 않는다.

## 확인 순서

| 항목 | 조작 | 기대 결과 |
|---|---|---|
| 기본 숨김 | 새 설정 또는 표시=숨김으로 확대 | 원본 편집창의 제목·도구·손잡이가 전혀 없다. 렌즈로 클릭·드래그 가능 |
| 5초 | 표시=5초 선택 후 설정 닫기, 확대 재시작, 영역 편집 완료 | 각 경계부터 얇은 선만 5초간 표시. 새 프레임·배율·렌즈 이동은 기한 연장 안 함 |
| 타이머 취소 | 5초 도중 영역 편집/복귀/닫기, 바로 재확대 | 옛 타이머가 새 표시를 일찍 숨기지 않는다. 복귀 뒤 선 잔류 없음 |
| 항상 | 표시=항상 | 선 위의 대상 버튼을 직접 클릭·드래그. 입력과 포커스는 대상 앱에 도달, 편집 chrome 없음 |
| 영역 재편집 | 렌즈 영역 편집 → 이동·8방향(N/NW/W/SW/S/SE/E/NE) 조절 → 완료 | 편집 중 실제 Down 없음. 완료한 원본 그대로 캡처. 물리 Up와 새 프레임 뒤 다음 클릭/곡선·왕복 드래그 |
| 편집+모달 | 편집 중 크기·비율/앱 설정 열고 닫기 | 편집창 유지, 완료 전 입력 재개 없음. 숨은 편집창 크기 설정도 완료 후 반영 |
| 일반·컴팩트×위·아래 | 4조합에서 렌즈 최소 크기와 큰 크기 비교 | 같은 Top/Bottom 설정이 도구막대를 이동. 컴팩트 제목/A·B 접힘, 모든 필수 버튼과 마우스 복귀 노출 |
| 컴팩트 크기 | 최소 440×280 DIP | 48 DIP 도구막대, 모든 버튼 hit target ≥44×44 DIP. 이동·편집·−/배율/+·손·설정·복귀·닫기가 겹치거나 잘리지 않음 |
| 렌즈 리사이즈 | 외곽 8방향, 설정의 렌즈 크기 조절 → 큰 손잡이 → 완료 | 반대 변 고정, 작업영역/최소 크기 제한. 조절 시작부터 끝까지 release·보류. 원본·배율 유지 |
| pan | 확대 후 손 도구로 중앙·모서리까지 이동, 크기 조절 반복 | 컴팩트는 스크롤바 없이 손 도구. 조절 뒤 visible viewport와 클릭 위치 일치 |
| 좌표 | 작은 목표의 중앙/네 모서리, 비정수 배율, 화면 우하단 경계 | 표시와 입력 오차 ≤1 원본 픽셀. viewport 우하단 밖은 입력 제외 |
| 혼합 DPI | 100/125/150/200% 모니터, 음수 원점, 경계 이동 | 렌즈 이동/크기·원본 편집 뒤 확대 화면과 클릭 일치. 원본이 의도 없이 바뀌지 않음 |
| 드래그 복귀 | 누른 상태에서 복귀/닫기, 창 겹침/경계 이탈 | 실제 버튼 해제 후 복귀. 복귀 버튼이 대상 클릭으로 전달되지 않고 누름 잔류 없음 |
| 캡처 실패 | 캡처 불가 표면·화면 구성 변경 | 실패 표시와 입력 중지. 사용자가 복귀·닫기·명시 중지를 하지 않았다면, 새 캡처 프레임을 받은 뒤 조작 요청이 자동 재개됨 |
| 윤곽선 제외 실패 | 제외 실패가 확인된 환경 또는 fake 테스트 | 표시창 Hide와 오류 유지. 정상 표시로 보고하지 않음. 실제 실패 유도 없이 확인 못 하면 미확인 |
| Stop·release 실패 | Esc/입력 실패 후 모달·편집·크기 조절 종료 | 조작 요청 부활 없음. 해제 실패 시 재개하지 않고 복귀로 해제 재시도 |
| 기억 켬 | 일반/컴팩트·상하단·표시 정책·원본·렌즈 rect·배율 변경 후 재실행 | 모양/정책과 마지막 배치 복원, 원본·렌즈 독립 |
| 기억 끔 | 기억 끄고 기본 원본·배율 지정 후 재실행 | 다음 배치는 기본값, 표시 정책/모양/상하단은 계속 기억. 입력·편집·타이머는 복원 안 함 |
| 구 JSON | 새 두 필드가 없는 settings.json으로 시작 | 기존 상하단/테마/기억/기본값 보존, Normal/Hidden 기본값. 손상 JSON은 기본 설정 |

## 자동 테스트는 사용자 실행

앱을 닫고 저장소 루트에서:

```powershell
dotnet build Magnifier.slnx --nologo
dotnet test Magnifier.slnx --nologo
```

Core crop/DPI·경계 테스트와 App fake/STA 회귀는 실제 대상 앱 반응을 증명하지 않는다. App 테스트는 OS 입력을 주입하지 않는다. 이번 에이전트 작업에서 실행 여부는 [run report](../notes/runs/2026-09-12-compact-lens-source-indicator.md)에 구분한다.

결과는 **표시 정책 / 모드·도구막대 위치 / DPI·배율 / 대상 앱 / 조작 / 실제 누름 잔류 / 결과**로 기록한다. 사용자 확인한 조합만 PASS로 갱신한다.
