# Pinte v0.1.0-beta.1

**Public preview · 2026-09-13 · [GitHub Release](https://github.com/ai-blink/pinte/releases/tag/v0.1.0-beta.1)**

This document is the version-controlled counterpart of the GitHub Release
notes. English is canonical; a Korean summary follows. Read the project guide
in [English](../../README.md), [한국어](../../README.ko.md),
[简体中文](../../README.zh-CN.md), or [日本語](../../README.ja.md).

## Added

- An independent live lens with normal and compact layouts.
- Source-area editing, lens resizing, zoom, pan/hand tool, and top or bottom
  toolbar placement.
- English, Korean, Simplified Chinese, and Japanese README files.

## Changed

- The hand tool now clearly shows whether pan mode is on or off.
- Lens resize chrome reserves less margin in small windows.
- Temporary capture failures pause input safely, retry automatically, and
  resume only after a fresh frame arrives.
- Pinte helper windows are intentionally excluded from capture to prevent a
  recursive mirror effect.

## Verification

- `dotnet build Magnifier.slnx --nologo` passed with 0 warnings and 0 errors.
- `dotnet test Magnifier.slnx --nologo` passed: 116 tests total.
- Included asset: self-contained Windows x64 single-file build.

## Known preview limitations

- This build is not code-signed.
- Secure desktops, protected content, elevated target applications, remote
  sessions, and target-specific input policies may prevent capture or input
  relay.
- Real target-application behavior still requires manual validation.

## 한국어 요약

마우스로 정밀하게 클릭·드래그하기 위한 Pinte의 첫 공개 프리뷰입니다.

### 추가

- 일반/컴팩트 레이아웃을 지원하는 독립 실시간 렌즈
- 원본 영역 편집, 렌즈 크기 조절, 배율, 손 도구 이동, 위/아래 도구막대
- 영어·한국어·중국어(간체)·일본어 README

### 변경

- 손 도구의 켜짐/꺼짐 상태를 명확히 구분합니다.
- 작은 렌즈에서 리사이즈 여백을 줄였습니다.
- 일시적인 캡처 실패 시 입력을 안전하게 멈추고 자동 재시도하며, 새 프레임을
  받은 뒤에만 조작을 재개합니다.
- 렌즈가 자기 자신을 반복 확대하지 않도록 Pinte 보조 창을 캡처에서 의도적으로
  제외합니다.

### 검증 및 프리뷰 제한

- 표준 build는 경고 0·오류 0, 자동 테스트는 총 116개 통과했습니다.
- 이 배포본은 Windows x64 자체 포함 단일 실행 파일이며 코드 서명되지 않았습니다.
- 보안 화면, 보호 콘텐츠, 관리자 권한 대상 앱, 원격 세션, 앱별 입력 정책은
  캡처 또는 입력 전달을 제한할 수 있습니다.
- 실제 대상 앱에서의 동작은 계속 수동 검증이 필요합니다.
