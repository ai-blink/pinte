# Pinte v0.1.0

**Official release · 2026-09-14 · [GitHub Release](https://github.com/ai-blink/pinte/releases/tag/v0.1.0)**

This document is the version-controlled counterpart of the GitHub Release
notes. English is canonical; a Korean summary follows. Read the project guide
in [English](../../README.md), [한국어](../../README.ko.md),
[简体中文](../../README.zh-CN.md), or [日本語](../../README.ja.md).

## Highlights

- Adds direct fine zoom control from 0.25× through 8× while retaining the
  fast zoom buttons.
- Retries transient lens geometry configuration failures so a valid lens can
  resume only after a newly captured frame is safe to use for input routing.
- Records frame freshness and relay state when input is paused or stopped,
  making a real-world input interruption diagnosable without affecting input
  release.
- Filters duplicate native Left Down messages and protects the relay queue so
  a second Down cannot terminate an already active click or drag session.

## Verification

- `dotnet build Magnifier.slnx --nologo` passed with 0 warnings and 0 errors.
- `dotnet test Magnifier.slnx --nologo` passed: 120 tests total.
- Included asset: self-contained Windows x64 single-file build. The final
  SHA-256 is published with the GitHub Release asset.

## Known limitations

- This build is not code-signed.
- Secure desktops, protected content, elevated target applications, remote
  sessions, and target-specific input policies can prevent capture or input
  relay.
- Real target-application behavior still requires manual validation on the
  Windows environments and target applications you use.

## 한국어 요약

Pinte의 첫 정식 릴리즈입니다.

### 주요 변경

- 빠른 배율 버튼을 유지하면서 0.25×부터 8×까지 직접 조절하는 세밀 배율 제어를
  추가했습니다.
- 일시적인 렌즈 geometry 구성 실패를 재시도하고, 안전한 새 캡처 프레임 뒤에만
  입력 전달을 재개합니다.
- 입력이 중지·일시 정지될 때 프레임 freshness와 relay 상태를 남겨, release 동작에
  영향을 주지 않고 실제 환경의 중단 원인을 진단할 수 있습니다.
- 중복 native Left Down을 걸러 동일 클릭·드래그 세션의 두 번째 Down이 입력 세션을
  종료시키지 않도록 했습니다.

### 검증

- 표준 build는 경고 0·오류 0, 자동 테스트는 총 120개 통과했습니다.
- Windows x64 자체 포함 단일 실행 파일 ZIP을 포함하며, 최종 SHA-256은 GitHub
  Release 자산과 함께 게시합니다.

### 알려진 제한

- 이 배포본은 코드 서명되지 않았습니다.
- 보안 화면, 보호 콘텐츠, 관리자 권한 대상 앱, 원격 세션, 앱별 입력 정책은 캡처
  또는 입력 전달을 제한할 수 있습니다.
- 실제 대상 앱 동작은 사용하는 Windows 환경과 대상 앱에서 계속 수동 검증이
  필요합니다.
