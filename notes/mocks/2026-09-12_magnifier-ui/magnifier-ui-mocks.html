이번 시안의 변경 범위 · 중간

크기·비율은 버튼으로 엽니다. 앱 전체 설정에는 화면, 영역·배율, 앱 정보 메뉴를 담았습니다. 1번·3번 스타일은 설정 안에서 전환합니다.

개발 연결 메모

이 파일은 WPF 변경 전 디자인 비교용 HTML 목업입니다. 채택한 두 스타일은 기존 SelectionOverlayWindow와 SelectionPreviewWindow 구조를 유지합니다. 아이콘 버튼 목표 크기는 44~48 DIP이며, 실제 WPF에서는 Fluent 리소스와 공통 ControlTemplate에 매핑할 수 있습니다. 샘플 SVG 안의 점 이동과 확대만 동작하며 화면 캡처·Win32 입력 전달은 하지 않습니다. 영역 이동은 샘플 화면의 좌표에 연결됩니다. 프리셋은 원본 영역의 픽셀 크기이며 목업은 2560×1440의 가상 화면 크기로 표시합니다. 프리셋 선택은 해당 크기와 비율을 적용하며 잠금 상태는 유지합니다. 비율 선택은 고정을 켜고 가로를 기준으로 세로를 맞춥니다. 방향 전환은 가로·세로를 바꾸며 가상 화면에 맞지 않으면 비율을 유지한 채 줄입니다. 화면보다 큰 프리셋은 비활성화합니다. 잠금 해제 시 자유롭게 조절합니다. 빠른 설정 패널은 바깥 클릭으로 자동으로 닫지 않습니다. 앱 전체 설정은 왼쪽 사이드바가 있는 별도 모달이며 화면·영역/배율·앱 정보로 구성합니다. 변경 사항은 즉시 반영하고 닫기 또는 Esc로 닫습니다. 브라우저 목업 전용 저장소에 스타일·테마·시작값과 마지막 영역 크기/비율/배율을 저장하며 실제 앱 설정 파일은 변경하지 않습니다. 실제 WPF 연결 시 앱 정보에 제품 버전과 진단 로그 접근을 추가할 수 있습니다. 실제 앱의 오류 시 release 정책은 별도 유지합니다.
