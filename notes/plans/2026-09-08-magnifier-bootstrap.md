# Magnifier 초기화 계획

## 1. 목표

무엇을 끝내야 하는가:
- 범용 안구마우스 돋보기 앱의 .NET 9 WPF 작업공간과 구현 가능한 개발 계약을 초기화한다.

완료 기준:
- WPF 솔루션이 빌드되고, canonical instructions·라이브 문서·필수 템플릿이 프로젝트 안에 존재한다.

## 2. 범위

이번에 할 것:
- Git 작업공간, WPF 스캐폴드, dev-docs, 구현 전 UX·기술 경계를 만든다.

이번에 하지 않을 것:
- 화면 캡처, 실제 마우스 전달, A/B 획의 제품 구현과 외부 패키지 추가.

## 3. 접근

1. .NET 9 WPF 솔루션을 초기화한다.
2. 승인된 UX 결정을 프로젝트 문서와 로드맵으로 옮긴다.
3. canonical `CLAUDE.md`와 dev-docs 템플릿을 만든다.
4. 빌드·문서 형태·비밀정보 검사를 실행한다.

중요한 판단 기준:
- UI가 Windows 입력 API를 직접 소유하지 않는다.
- 실제 입력은 별도 구현·수동 확인 전까지 열지 않는다.

## 4. 검증

통과해야 할 확인:
- `dotnet build Magnifier.slnx --nologo`
- 문서 형태 검증, `git diff --check`, 변경 문서 비밀정보 검사

## 5. 남는 리스크

주의할 점:
- 대상 앱의 입력 수용 방식과 권한 경계는 아직 수동으로 검증되지 않았다.

후속으로 넘길 것:
- M1 영역 선택 오버레이와 확대 미리보기 구현.
