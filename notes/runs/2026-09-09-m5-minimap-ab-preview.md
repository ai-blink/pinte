# M5 미니맵 캡처와 A/B 표식 실행 기록

날짜: 2026-09-09

## 목적

사용자 지정 데스크톱 사각 영역을 미리보기 창 위치와 무관하게 계속 표시하고, 비활성 입력 상태에서 A/B 지점과 직선 계획을 정확히 확인한다.

## 변경

- 미리보기 창에 Windows `WDA_EXCLUDEFROMCAPTURE`를 적용하고, 원본 영역과 겹칠 때 프레임 갱신을 보류하던 경로와 원본 영역 밖 자동 배치를 제거했다.
- A/B 표식은 실제 입력에 쓰는 정수 화면 좌표와 분리해, 클릭 당시의 정규화된 미리보기 좌표로 배치한다.
- A와 B가 모두 지정되면 노란 점선으로 예정된 직선 획을 표시한다.
- 실제 입력은 기본 비활성이고 `A→B 실제 입력 허용`을 명시적으로 켠 뒤에만 실행 버튼을 활성화한다.

## 검증

- `dotnet build Magnifier.slnx --nologo`: 경고 0, 오류 0.
- `dotnet test Magnifier.slnx --nologo`: Core 테스트 7개 통과.
- 사용자 수동 확인: A/B 표식 중심이 클릭 위치와 일치함.

## 남은 M5 확인

- 브라우저 마스크 페인팅 화면과 Blender 5.2에서 미리보기를 선택 영역 위에 겹친 상태로도 프레임이 계속 갱신되는지 확인한다.
- 실제 입력은 대상 창·비관리자 권한 상태·Esc 취소 절차를 사용자가 확인한 뒤, 한 번의 짧은 A→B 획으로만 검증한다.
