# M5 보이는 화면 A/B HTML 목업 기록

날짜: 2026-09-09

## 목적

최종 구현 전, 선택한 보이는 화면 영역의 A/B 표식·직선 계획·실제 한 획 전달 흐름을 브라우저에서 조작해 검토한다.

## 현황 반영

- 실제 App은 A/B 표식의 정규화 좌표와 미니맵 캡처 제외까지 구현·검증됐지만, 현재 작업 트리의 미리보기 비간섭 전달과 미리보기 안 입력 활성화 변경은 아직 build/relaunch 검증 전이다.
- 목업은 그 차이를 숨기지 않고, 실제 입력을 보내지 않는 검토 전용 데모로 표시한다.

## 목업 구성

- `notes/mocks/2026-09-09_m5-visible-surface-ab/m5-visible-surface-ab-mock.html`: A/B 지정, 표식·연결선, 실행 허용, 카운트다운·Esc 취소, 미리보기 비간섭 전달 시연, 완료 기준 탭.

## 다음

사용자가 목업의 흐름을 승인하면, 현재 App 변경을 표준 실행본으로 build/relaunch해 브라우저와 Blender에서 실제 검증한다.
