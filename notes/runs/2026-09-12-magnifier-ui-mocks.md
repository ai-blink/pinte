# Magnifier UI — 채택한 두 스타일과 앱 전체 설정

- 사용자 요청: 투박한 UI 정리, 실시간 입력 켜기·끄기 UI 제거, 아이콘 중심 WPF 화면 논의 후 HTML 목업 3개 비교.
- 산출물: [자기완결 HTML 목업](../mocks/2026-09-12_magnifier-ui/magnifier-ui-mocks.html). 외부 글꼴·이미지·CDN·빌드 의존성이 없다.
- 사용자 후속 결정: 1번·3번을 모두 채택하고 선택 가능하게 한다. 2번은 비교에서 제외한다. 실제 WPF 적용은 후속 범위다.
- 1번: 밝은 표면과 상단 도구막대.
- 3번: 확대 화면 아래의 도구막대. 창과 함께 이동하며 자동으로 숨지 않는다.
- 공통: 시작·영역 지정·확대 단계, 원본 테두리와 독립 렌즈, 배율, 항상 보이는 복귀. 입력 전환 버튼과 장문 상태 표시는 없다.
- 영역 재지정 버튼은 제거한다. 확대 중에도 원본 테두리를 이동·크기 조절하면 즉시 반영한다. 복귀 후 시작 화면에서 영역을 지정하는 진입 과정은 유지한다.
- 원본 픽셀 크기 프리셋: 16:9 계열 320×180~1920×1080, 4:3 계열 640×480·800×600·1024×768, 정사각형 480·720·1080. 배율과 원본 크기는 별도다.
- 16:9·4:3·1:1 비율 선택, 가로/세로 전환, 비율 고정 켜기·끄기를 추가했다. 비율을 선택하면 고정이 켜지고 테두리 조절에도 유지한다. 프리셋은 크기·비율을 적용하며 기존 잠금 상태를 유지한다.
- 목업의 가상 화면은 2560×1440이며 영역 최대치는 2400×1320이다. 방향 전환이 이 범위를 넘으면 비율을 유지하며 줄이고 실제 적용 크기를 표시한다. 화면보다 큰 프리셋은 비활성화한다. 실제 앱의 모니터·DPI 처리 구현은 아니다.
- 사용자 후속 결정: 크기·비율은 설정 버튼으로 여는 패널을 채택한다. 항상 보이기 비교 선택은 제거했다. 패널은 값 변경이나 바깥 클릭으로 자동 닫히지 않는다.
- 앱 전체 설정은 별도 톱니바퀴로 연다. 시작 창·원본 테두리·확대 도구막대에서 접근하며, 현재 영역의 크기·비율을 여는 슬라이더 아이콘과 구분한다.
- 전체 설정 목업은 왼쪽 사이드바, 오른쪽 설정 내용, 아래 닫기 버튼이 있는 별도 모달이다. 변경 사항은 즉시 반영하며 바깥 클릭으로 닫지 않는다. 닫기·X·Esc는 설정창만 닫는다.
- 메뉴 제안은 3개다. `화면`: 1번/3번 스타일 및 시스템·밝게·어둡게 테마. `영역·배율`: 이전 크기·비율·고정 상태·배율 기억, 기본 원본 크기와 시작 배율. `앱 정보`: 간단한 마우스 사용법. 실제 앱 연결 시 제품 버전과 진단 로그 접근을 추가할 수 있다.
- 이전 값 기억을 켜면 기본 시작값 입력은 비활성화한다. 끄면 선택한 기본값으로 다음 영역 지정을 시작한다. 스타일·테마·시작값과 마지막 영역 크기/비율/배율은 브라우저 목업 전용 저장소에 저장하며 WPF 앱 설정 파일과 별개다.
- 목업 안에서 원본 위치·크기, 렌즈 위치, 1~4배 확대, 샘플 점 이동, 복귀를 연결했다. 실제 화면 캡처·Windows 입력은 하지 않는다.
- 확인: 인라인 JavaScript 구문 통과, 정적 ID 중복 0, 외부 자산 의존 0, 아이콘 참조 누락 0, 로컬 HTTP 200. 실제 브라우저 조작 검사는 사용자가 직접 한다.
- WPF 소스·빌드·실행본·상태 계약은 변경하지 않았다. 목업은 새 제안이며 현재 제품 기능으로 기록하지 않는다. 커밋·푸시 없음.
- 사용자 “아주 좋아 계획서 만들어줘”로 전체 설정 목업을 승인했다. [WPF 구현 계획](../plans/2026-09-12-magnifier-ui-settings.md)에 단계·파일 범위·사용자 확인 기준을 정리했다. 실제 WPF 구현은 미착수다.
