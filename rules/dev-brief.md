# 개발 브리프

- 제품: 범용 Windows 안구마우스 정밀 페인팅 돋보기.
- 사용자: 일반 포인터를 제공하는 안구마우스로 화면 페인팅을 하는 사용자.
- 핵심 과업: 선택한 보이는 화면 영역을 확대해 지속 조작을 같은 물리 좌표로 전달하고, A→B 직선 획을 보조 기능으로 안전하게 실행한다.
- UX 원칙: A/B 표식과 직선 계획을 먼저 보이고, 실제 실행 제어는 같은 미리보기 안에서 명시하며, 클릭 한 번의 명령·길게 누름 수치 반복·Esc 취소를 제공한다.
- 구현 원칙: .NET 9 WPF UI와 Windows Infrastructure를 분리한다.
