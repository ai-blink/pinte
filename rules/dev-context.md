# 재개 컨텍스트

- 브랜치: `main`.
- 현재 상태: M2 실제 화면 캡처·좌표 변환과 M2.1 실시간 미리보기가 build·test·사용자 수동 확인을 통과했다. 다음 목표는 M3 입력 gate·release 경로의 최소 계약이다.
- 사용자 승인 설계: 범용 Windows 오버레이, 이동 가능한 상호작용 확대창, 길게 누름 수치 조절, A→B 단일 직선 획.
- 최근 증거: `dotnet build Magnifier.slnx --nologo` 경고·오류 0, `dotnet test Magnifier.slnx --nologo` Core 테스트 3개 통과, 사용자가 실제 캡처와 실시간 화면 변화 반영을 확인했다 (2026-09-08).
- M3 완료선: 실제 입력은 기본 비활성으로 유지하면서, 명시적 gate와 취소·창 닫기·capture 손실에도 release로 끝나는 단일 입력 세션 계약을 구현한다.
- M3 수락 확인: 솔루션 build/test와 실제 창에서 비활성 입력이 대상 앱에 전달되지 않는지 확인한다. 입력 활성화 검증은 별도 사용자 승인 뒤에만 수행한다.
- 중단 규칙: M3 계약이 통과하면 연속 입력·자유 경로 재생·대상 앱 통합은 시작하지 않는다.
