# UX 원칙

- 플로팅 도구의 첫 행동은 `영역` 선택이다.
- 확대창은 원본 영역을 바꾸지 않고 표시 위치와 크기만 바꾼다.
- 페인팅, 창 이동, 원본 영역 재지정은 동시에 활성화하지 않는다.
- 모든 실제 입력 상태는 미리보기·대기·실행·실패 중 하나로 큰 텍스트로 표시한다.
- `− / +` 수치 버튼은 단발과 길게 누름 반복을 모두 지원한다.
- `A 지정` 또는 `B 지정` 뒤의 이미지 클릭만 고정 표식을 만든다. 일반 hover 표식은 만들지 않는다.
- A/B 표식의 중심과 직선 계획은 같은 정규화된 미리보기 좌표를 사용해, 확대·letterbox·DPI 변화 뒤에도 클릭 지점과 일치한다.
- 실제 입력 허용과 `실제 A → B 실행`은 미리보기의 같은 조작 줄에 둔다. 사용자가 뒤에 있는 기본 창에서 별도 제어를 찾아야 하는 흐름을 만들지 않는다.
- A→B 실행 직전에는 미리보기 자신이 선택 영역의 클릭을 받지 않게 잠시 비켜서며, 대상 창을 식별하거나 제한하지 않고 보이는 화면 좌표로 전달한다.
- A/B 지정 모드의 이미지 클릭은 표식만 만든다. 실시간 조작은 A/B 실행과 섞지 않는 명시적 별도 모드로 설계·검증한다.
- 확대된 화면의 지속 조작이 실제로 전달되기 전에는, 현재 A/B 전용 화면을 “실시간 돋보기”라고 안내하지 않는다.
