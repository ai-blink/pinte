# UX 원칙

- 첫 행동은 `확대 시작`이다. 상시 원본 테두리와 독립 렌즈를 보기 모드로 연다.
- 원본 테두리의 이동·크기 손잡이만 캡처 영역을 바꾼다. 내부의 실제 화면을 가리지 않는다.
- 렌즈 제목을 옮겨도 원본 영역은 유지한다. 원본 영역 조절은 렌즈 위치를 자동 변경하지 않는다.
- 조작 시작·중지·원래 화면·배율은 렌즈와 함께 이동하며 콘텐츠처럼 확대되지 않는다.
- 직접 클릭·연속 드래그가 주력이다. 명시적 조작 시작 전에는 입력을 전달하지 않는다.
- 입력이 활성화되었거나 누름·물리 해제 대기 중이면 영역·배율·창 배치를 잠근다.
- 콘텐츠 경계에서 마지막 유효 원본 위치에 Up을 보낸 뒤 보기로 전환한다. 복귀 이동·클릭으로 긴 획이나 추가 클릭을 만들지 않는다.
- 원래 화면은 입력 해제 → 입력 끄기 → 두 창 숨김 → 진입 버튼 복원 순서다. 재진입 시 입력 허용은 복원하지 않는다.
- 배율은 실제 표시 배율을 안내한다. 화면에 맞춰 제한한 경우 요청 배율과 맞춤 결과를 구분한다.
- A/B 지정·카운트다운·직선 실행은 접힌 보조 도구에 두고 직접 조작과 상호 배제한다. A/B 선택 클릭은 표식만 만든다.
- A/B 표식과 직선 계획은 정규화 좌표를 사용한다. 직접 조작 중 가상 포인터는 A/B 표식과 구분한다.
- 현재 배율·카운트다운 버튼은 단발 클릭이다. 길게 누름 반복·우클릭·휠 등 보조 UX의 확장은 핵심 검증 뒤 진행한다.
- 입력 실패·해제 대기·보기 상태를 구분하고, API 수락을 실제 대상 반응으로 안내하지 않는다.
- 구현 후보의 실사용 수락은 `BLOCKED / NEEDS_USER_UI_CHECK`다. [구현 기록](../notes/runs/2026-09-10-two-window-implementation.md)의 미검증 범위를 유지한다.
